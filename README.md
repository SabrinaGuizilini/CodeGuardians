# 🛡️ CodeGuardians

CodeGuardians é um jogo educacional desenvolvido como Trabalho de Conclusão de Curso (TCC) com o objetivo de estimular e facilitar o aprendizado de testes funcionais de software por estudantes da área da computação.

O projeto foi desenvolvido utilizando **Vue.js** e apresenta conceitos fundamentais de testes de software por meio de simulações práticas em um ambiente gamificado.

## 🎯 Objetivo

O jogo busca tornar o aprendizado de testes de software mais motivador e acessível, permitindo que os estudantes pratiquem a elaboração e execução de casos de teste em cenários inspirados em situações reais do desenvolvimento de software.

## 📚 Conteúdo Abordado

Ao longo de 8 níveis, o jogador aprende e aplica conceitos relacionados à técnica funcional de testes de software, incluindo:

* Particionamento de Equivalência
* Análise do Valor Limite
* Tabela de Decisão
* Teste de Unidade
* Teste de Integração
* Teste de Sistema

## 🎮 Sobre o Jogo

Em um cenário pós-apocalíptico, o jogador assume o papel de um testador responsável por identificar falhas em sistemas críticos. Cada fase apresenta desafios práticos que exigem a aplicação dos critérios de testes funcionais para avançar na história.

## 🛠️ Tecnologias Utilizadas

* Vue.js
* JavaScript
* HTML5
* CSS3

## 📊 Avaliação

O jogo foi avaliado por 17 estudantes de cursos de graduação da área da computação que estavam cursando ou já haviam cursado disciplinas relacionadas à Engenharia de Software.

Os resultados indicaram que o CodeGuardians:

* Aumentou a motivação dos participantes para aprender testes de software;
* Facilitou a compreensão dos conceitos teóricos;
* Auxiliou na aplicação prática dos critérios de testes funcionais;
* Proporcionou uma experiência de aprendizagem lúdica e envolvente.
